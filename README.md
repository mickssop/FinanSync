## Desenvolvimento

- `npm install`: ferramentas de desenvolvimento.
- `npm start`: executar.
- `npm run check`: sintaxe.
- `npm test`: todas as verificações.
- `npm run dist-unpacked`: gerar distribuição no Windows.
